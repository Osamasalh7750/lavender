# 🚚 منصة لافندر للخدمات اللوجستية (Lavender Logistic) - النسخة الثابتة (Static Showcase)

نسخة ثابتة (Pure Static) متكاملة، تعمل مباشرة بمجرد النقر المزدوج على ملف `index.html` دون الحاجة لأي سيرفر محلي، وجاهزة 100% للرفع المباشر على **GitHub Pages** للحصول على رابط ويب فوري وإرساله لإدارة شركة لافندر.

---

## 🌟 مميزات هذه النسخة:

1. **تشغيل فوري بالنقر المزدوج (Double-Click):**
   - تعمل عبر بروتوكول `file:///` المحلي دون أية أخطاء.
   - جميع الروابط والصور نسبية (`./images/`, `./css/`, `./js/`).

2. **شريط التنقل السريع الفوقي (Top Quick-Switcher):**
   - شريط عائم في أعلى الصفحة يضم أزراراً لجميع صفحات وعمليات المنصة الـ 12.
   - يتيح لك أو لأي شخص تعطي له الرابط التنقل المباشر وتجربة أي شاشة بنقرة زر!

3. **تغطية شاملة لكافة صفحات وعمليات موقع لافندر الأصلي:**
   - **`#/landing`**: صفحة الهبوط التعريفية المتكاملة مع حاسبة النقل والتسعير الفورية بالريال السعودي.
   - **`#/home`**: منصة الطلب والتوريد B2B وتصفح المتاجر والموردين.
   - **`#/shop`**: المتجر واستعراض المنتجات مع دعم **الطلب بالوزن (كجم)** وبالصناديق.
   - **`#/order_step_one`**: جدولة الشحن وتحديد درجات حرارة التبريد (مبرد 0-4°C / مجمد -18°C / جاف).
   - **`#/order_step_two`**: خيارات الدفع B2B (آجل للشركات، مدى، كود شحن، كاش) ومراجعة السلة.
   - **`#/tracking`**: التتبع الميداني الحي للأسطول عبر GPS ومستشعر الحرارة IoT المباشر.
   - **`#/order_detail`**: الفاتورة الإلكترونية مع ميزة **رفع الفاتورة المختومة (e-POD)** بعد الاستلام.
   - **`#/order_list`**: سجل الشحنات والطلبات السابقة والحالية مع حالات التوصيل.
   - **`#/locations`**: إدارة فروع وعناوين الاستلام والتأكد من نطاق التغطية.
   - **`#/login` & `#/signup`**: تسجيل الدخول وتسجيل حساب منشأة جديد.
   - **`#/admin`**: لوحة تحكم إدارة العمليات B2B Admin Dashboard.

4. **متجاوبة بالكامل 100% مع جميع الشاشات (Mobile, Tablet, Desktop):**
   - تصميم حديث ومتقن (Lavender Glassmorphism) يدعم الهواتف والشاشات الصغيرة بسلاسة فائقة.

---

## 🚀 كيفية رفع الموقع على GitHub والحصول على رابط مباشر (GitHub Pages):

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub (مثلاً: `lavender-showcase`).
2. ارفع كافة الملفات الموجودة داخل هذا المجلد (`index.html`, مجلد `css`, مجلد `js`, مجلد `images`).
3. من صفحة المستودع على GitHub:
   - ادخل على **Settings** ➔ **Pages**.
   - تحت قسم **Build and deployment**، اختر الفرع **main** أو **master** واضغط **Save**.
4. خلال دقيقة واحدة، سيمنحك GitHub رابطاً مباشراً يمكنك إرساله للشركة فوراً، مثل:
   `https://username.github.io/lavender-showcase/`
